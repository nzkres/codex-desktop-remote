# Android alpha.15 私有更新发布记录

`0.1.0-alpha.15` / versionCode15 / 私有序号9 已发布并从手机使用的HTTPS路由完成实际鉴权完整APK下载、大小、哈希与签名核验。手机安装和真机视觉尚未验收。本轮最终版本为alpha.15，alpha.14包和索引作为不可覆盖的历史保留。

## 手机更新与使用

保留原应用、账号与应用数据，在“我的 → 版本与更新说明 → 检查更新”覆盖安装最终alpha.15。

- “我的 → 对话与玻璃 → 终端皮肤 → 额度样式”：光格数字、环形光格、圆内矩阵、双额度环、星核扩散，选择在本机持久化。全部数字位于环中央，数字由方格组成；双额度环的两条环分别映射同一账号两个真实窗口，中央两组数字分别标注窗口。
- 已删除实时背景预览、输入框额度和设备名称下重复额度条。对话列表保留单行额度，点击才看套餐、重置及采样时间。字体、玻璃、速度与背景亮度设置保留；核心流光亮度也控制额度图形，0关闭图形。
- **最终alpha.15**：Plus显示实际短期和周额度，Pro仅显示真实周额度单环；旧五小时样本不充当Pro额度。没有周快照显示—，没有套餐字段显示套餐未同步并兼容实际窗口，不猜测、不补满。alpha.14是基于实际窗口数的初版；alpha.15补齐正式套餐规则。
- 套餐识别需配套Windows alpha.18提供同一授权任务事件中的白名单plan_type；已发布到Windows原私有源。等任务完成走原连接器正常断开、检查更新、下载安装及重新连接流程。本次没有替用户安装、停止连接器或修改原身份、回执、保护标志。
- 切换电脑使用该电脑快照；相同账号共享额度。失败、离线、重启未核对及超过10分钟/重置时间显示上次，不用本地计时器伪造扣减。原始快照不删除，不改变发送、问答、草稿或权限协议。

官方套餐定义及显示数据约定见[额度说明](QUOTA-CORE-GLOW.md)。
