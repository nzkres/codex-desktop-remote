# 手机额度与核心网格流光

Android alpha.11 的输入框显示电脑当前任务记录的账号额度快照，点击查看各额度窗口、重置时间和采样时间。窗口名称根据真实分钟数格式化，不硬编码为五小时/一周。额度与同账号共享，不是本轮剩余 token。Windows alpha.17 转发额度字段；旧连接器明确显示未同步，不猜测零或满额。

连接器先通过现有任务范围、原生快照和权限核验，再通过只读 SQLite 找到该任务日志；校验日志 session_meta 的 id 及 sessions 路径边界，拒绝链接/目录联接，仅扫描末尾2MiB。输出只含额度 id、采样时间、usedPercent、窗口分钟数和重置时间，不转发日志、聊天、credits 或凭据。20秒有界缓存，不新增后台网络请求或执行器。手机将超过10分钟、未来异常时间或已到重置时间的数据标记上次额度，不推算为满额。切换任务/电脑沿用原隔离。

皮肤入口仍在“我的 → 对话与玻璃”。背景光格、背景线及核心流光各有0–400%亮度与实时预览，使用本机 SharedPreferences 持久化；不重置旧速度、字体和玻璃选择。核心位于网格交点，流光沿网格折线向边缘外散，保留随机光蛇/方块/亮格。工作加速，停止时按现有设置慢速或静止；后台和减少动画停止时钟，核心保留静态分支。正文颜色不跟随背景亮度。

合成测试覆盖网格对齐、外散方向、明暗边界、额度缺失/过期/实际窗口、跨任务和日志路径越界。真实只读额度读取通过；独立原生快照候选探针暂未获得流快照，不把读取器成功当成手机端到端成功。发布和实机验收另记。

## alpha.13 每台电脑的额度背景光

每个中继/账号作用域单独加密保存deviceId→threadId→usage快照。对话读取时记入对应电脑；对话页前台依次对活跃在线电脑普通只读同步，每轮后间隔30秒。优先最近已读取任务；首次可读取该电脑列表中最近更新任务。所有请求仍走原任务授权、原mobile-sync接口且openDesktop=false，不切换Desktop对话，不发送消息/答案。离线/暂停跳过；窗口无有效数据时显示未同步。

每台设备名下显示优先codex窗口剩余额度数字和淡色背景光；选择电脑展示该机快照所有窗口、实际时长及采样时间。切换设备重建对应显示，绝不沿用其他设备的值。背景填充映射真实remaining/100，仅对观测值变化进行650ms过渡；减少动画、系统关闭动画或后台时静态。数字是真实观测，不在两个快照间自行扣减。真实重置后的新快照可增加；晚到旧采样不能覆盖新采样。

账号额度共享，不是独立电脑预算，也不是token累计、金额或计费余额。读失败、重启尚未重新核对、超过10分钟或越过重置时间显示上次/待核对；读失败保留旧快照但不冒充实时。原连接器未提供额度则未同步；显示不证明真实手机已安装。
