# Android alpha.12 私有更新发布记录

Android `0.1.0-alpha.12` / versionCode `12` / 私有更新序号 `6` 已发布到原HTTPS更新源。实际HTTPS完整下载、原APK证书、索引签名、包内版本说明和trust已独立核验。手机安装与真实任务接续仍待用户验收。

## 更新与体验

1. 等当前任务结束，保留原APP、账号与电脑配对。在“我的 → 版本与更新说明 → 检查更新”确认alpha.12并按系统提示覆盖安装，不卸载、不清数据。
2. 进入“对话”，顶部一行横向切换电脑；状态文字与字色区分连接，选中只有细线。连接中沿灰色字形向右扫光，不扫背景；对话行以淡斑马纹透出共用核心流光。
3. 点击运行中/待回答数量只筛选当前电脑；状态从原只读接口分批核对，每批最多12段，未核对与超过2分钟的状态不冒充空闲。点“继续核对”读取下一批。
4. 点“去回答”定位原问题。提交中禁用操作，原生证据确认后显示电脑已收到并更新数量。明确未发送失败保留答案；未知结果只刷新核对。电脑已处理、题目变化与旧题关闭不能重复提交。原协议不能明确区分的关闭原因继续显示“已处理或失效”，不编造电脑回答证据。
5. “任务仓库”新建想法、确认任务、开始开发、标记完成并验收；JSON导入先核对，导出由用户选择文档位置。资料按账号加密保存在手机，独立于执行电脑。没有自动GitHub读取/写入或模型生成计划；见[数据约定](PROJECT-REPOSITORY.md)。
6. “我的”保留设备配对管理、皮肤、字体、光格/线条/核心流光独立亮度、额度和更新入口。任务更新门禁与未知发送回执保护未放宽。
