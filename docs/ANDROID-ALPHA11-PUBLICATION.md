# Android alpha.11 / Windows alpha.17 发布实录

手机 alpha.11/versionCode11/sequence5 于 2026-10-15T04:42:20.822415+00:00 发布；电脑连接器 alpha.17/sequence13 于 2026-10-15T04:41:17.406509+00:00 发布。两端原私有 HTTPS 更新源都完成正常 TLS、账号鉴权、完整包大小/SHA256 和发布签名复验；匿名索引与包均401，验收临时会话单独注销。手机与电脑实际安装均未自动完成；当前电脑仍alpha.16。

## 如何更新并体验

1. 等当前任务结束，电脑连接器点“断开连接”，再点“检查更新 → 下载并安装”，确认alpha.17，完成后重新连接。保留原身份和回执，不卸载、清数据或重新配对。若仍有其他运行任务或未知回执，正常门禁会阻止安装，本次不绕过。
2. 手机原APP“我的 → 版本与更新说明 → 检查更新”，确认alpha.11并按系统提示覆盖安装。先更新手机也可体验背景；额度须电脑alpha.17配套。
3. “我的 → 对话与玻璃 → 终端皮肤”，分别调节“背景光格亮度 / 背景线亮度 / 核心流光亮度”，范围0–400%，有实时背景预览与本机持久化；开启“核心外散流光”，沿网格从核心向外流动。保留既有随机光蛇/方块、配色、速度和工作加速；后台和减少动画静止。
4. 对话输入框额度条可展开查看各窗口剩余百分比、重置时间和采样时间。数据来自当前任务最近的Desktop额度记录，账号共享，不是本轮token或实时账单；超过10分钟、已过重置时间或时间异常显示上次额度。旧连接器明确提示未同步。
