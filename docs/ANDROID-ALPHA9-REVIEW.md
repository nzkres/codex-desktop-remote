# Android alpha.9 终端玻璃皮肤

用户确认目标为 Desktop Remote Lite（codex-desktop-remote），并授权将已确认的动态预览封存、开发为新版。预览归档 SHA256 为 `bfbfda8bca1f67cec0f4c9821f725c8936888a9567aca9b292ff05c6d8dec2f6`。不改旧 Codex Remote。

## 体验入口

- 我的 → 对话与玻璃：三种玻璃、11 个字体选项（8 款内置开放字体和 3 种系统字形）、字色、文字阴影、背景配色、动效、速度、亮度、彩色与空闲静止；配置保存在本机 appearance 偏好中。字体许可证和来源摘要随包提供。
- 对话页：网格统一为 24dp，光蛇随机转向，方块随机形状和旋转。运行速度为设置的 1.5 倍；空闲为 0.25 倍或静止。后台、减少动画或关闭系统动画时停止背景循环。计时仍来自 Desktop 回合开始时间，减少动画不冻结实际时间。
- 多轮历史：最后一条完全离开阅读区域的用户消息显示在直角背景吸顶条；当前消息重新进入窗口时恢复上一轮摘要。点击沿用原消息 id 分页定位，不发送新任务。
- 输入框：左上 Working 点呼吸与时间；等待处理显示文字；发送后保留输入框，停止按钮在发送箭头原位。模式与模型在同一弹窗，输入栏用短竖线分隔。回到最新为右侧矢量下箭头，点击区 48dp。
- 问答：选项和说明合并在同一可选行，保留 48dp 触控高度。原有题目 revision、加密草稿、提交未知状态核对和电脑已答状态不变。

## 真实能力边界

目前没有模型读取/修改协议，弹窗只说明由 Desktop 管理；模式按连接器 capability 禁用。异步问题沿用 alpha.8 的 desktop_required 状态，不宣称手机可回答。Android 12 以上玻璃采样真实背景并模糊；旧系统用更强半透明底色。正文可选手写字体，代码继续 JetBrains Mono。
