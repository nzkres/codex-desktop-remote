# 手机新建对话：本地构建与验证记录

2026-10-16，按用户确认先完成构建与测试，当前无 USB 手机。未发布私有更新索引、未替换现有连接器、未安装手机。代码在本地分支 `feature/mobile-create-conversation`。

## 实现

正式对话首页选择电脑后点击“新对话”，选择该电脑已有本机项目目录。标题可选，消息作为草稿保存；创建完成后进入真实对话，再由用户点击原发送按钮。模式/模型不提供未接通的切换。创建请求在手机按账号/电脑加密保存，提交后保持原编号及内容，超时可以“核对并继续”，不会重复创建。

本机创建辅助进程仅执行 stdio initialize、thread/start、thread/name/set、thread/read，命名落盘并正常退出后交回原生 Desktop。没有模型输入、网络监听、线程复制或 Desktop 内部文件修改。父进程的工具管道、来源覆盖及线程/会话标识不会借给辅助进程；父环境与沙箱约束不改。原理参见 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)，空对话命名和接管行为以本机实验为准。

创建回执与原发送/问答账本共存，未知结果继续阻止发送、更新及安全断开确认。保存了真实 ID 的接管失败只继续原对话接管，不再启动创建。旧发送协议、消息编号和回执均未替换。
