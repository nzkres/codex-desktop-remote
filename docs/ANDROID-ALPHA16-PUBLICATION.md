# Android alpha.16 手机内原生预览发布记录

`0.1.0-alpha.16` / versionCode16 / 私有序号10 已发布原更新源。实际HTTPS鉴权完整APK下载、大小、哈希及元数据签名已核验；手机安装和真机视觉尚未验收。

## 手机操作

1. 保留原应用和数据，在“我的 → 版本与更新说明”检查更新并覆盖安装alpha.16。
2. 打开“我的 → 界面预览 · 未读与发送按钮”，无需外部网页或额外登录。皮肤、字体、玻璃和网格沿用当前设置。
3. 点“演示完成 → 未读”，再打开演示对话。未看到最新结果保持未读，滑到最新结果后变已读；返回、关闭再开仍记忆。新完成结果重新标未读。
4. 从“发送结果”选择成功、未送达或回执未知，再点预览输入框右侧箭头。箭头固定，细环旋转；成功确认后勾、运行后方形停止。失败保留演示输入，未知禁止重发。

本版只新增独立原生演示入口。正式对话的运行计数、已读及发送按钮没有替换；演示不发送真实消息、不代表Desktop实际收到。仅演示阅读水位写入独立interface-preview-only-v1，演示草稿只在内存，不接入正式草稿、身份或回执。
