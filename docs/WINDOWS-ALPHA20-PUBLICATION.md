## 安装与验收边界

任务空闲后，在原受管连接器正常断开并确认安全，再检查更新、下载并安装alpha.20。完整配对且无运行保护的窗口在普通打开、更新激活后发起一次自动连接；隔离候选不提前连接接单，不增加Windows开机自启。保留原身份及回执，不重新配对或删除state。

候选失败时保留固定白名单错误码；旧助手仍可能显示通用失败，可查看`state/candidate-health.json`对应版本的失败码。任务忙碌、未知回执、权限变化、异常退出仍阻止升级。

本轮没有停止现用连接或在真实任务运行中切换版本。新包发布、完整下载和旧客户端验包通过，不等于本机安装、候选真实健康检查、自动连接或手机新发送已完成实机验收。真实升级结果另记。
