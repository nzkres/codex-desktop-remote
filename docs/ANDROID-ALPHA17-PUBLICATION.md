# Android alpha.17 账号额度动效预览发布

`0.1.0-alpha.17` / versionCode17 / 私有序号11 已发布原更新源并完成真实HTTPS鉴权全包下载。手机安装与真机视觉尚未验收。

## 手机体验

保留原应用和数据，在我的 → 版本与更新说明检查并覆盖更新。我的 → 界面预览 · 额度与交互默认进入额度动效预览；顶部未读与发送可回上一版交互。

1. 三台合成设备初始全部停止。保持选中工作电脑，开启家用电脑开关；同账号A的额度应由暗到亮，约5秒渐强呼吸、外围双光弧从近静止逐步加速。
2. 两台A都启动后，只停止其中一台，额度继续运行；停止最后一台才渐弱、渐慢。重启从当前强度继续，不重置转角。
3. 在工作电脑和家用电脑之间切换，共用同一账号动画模型；切到账号B仅看B自身任务，B/Pro单周环、A/Plus演示双窗口。
4. 底部可切五种额度皮肤。数字保持68%/43%（A）或76%（B），不模拟扣减。沿用字体、玻璃、背景亮度；核心亮度为0时可临时开启本次预览，不改皮肤设置。
5. 减少动画时静态高亮；后台无动画循环，恢复不追赶后台时间。

仅预览使用合成账号与任务开关，不读取真实账号标识、令牌、Gateway或正式运行信号；正式跨电脑账号聚合尚未接入。不能凭Plus/Pro套餐认定同账号，也不能把未知或连接在线当作任务运行。
