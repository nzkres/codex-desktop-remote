# Android 手机端版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.11（2026-10-15）

对话输入框显示账号额度快照，增强可调背景光与核心外散网格流光。

### 更新

- **输入框额度与重置时间**
  - 体验：对话输入框点额度条，查看各窗口剩余百分比、重置时间和采样时间。
  - 验证：额度按真实窗口显示；过期、缺失和旧连接器不显示虚构的满额或零额度。
- **核心外散网格流光与独立亮度**
  - 体验：我的 → 对话与玻璃 → 终端皮肤；调节背景光格、背景线、核心流光三种亮度，并查看实时预览。
  - 验证：光沿网格从核心向外流动，工作时加速；亮度0–400%可调，关闭/减少动画/后台静止，重开保留设置。

### 限制

- 额度来自同一任务最近的 Desktop 记录，需要支持额度同步的 Windows 连接器；并非实时扣费账单，超过10分钟或重置时间后标记过期。
- 背景显示效果仍受手机屏幕、深浅色主题与玻璃材质支持影响；前景文字不随背景亮度变淡。

## 0.1.0-alpha.10（2026-10-15）

更新失败显示具体原因，区分终端暂停、离线与未确认发送回执。

### 更新

- **更新状态精确诊断**
  - 体验：我的 → 版本与更新说明 → 检查更新；检查和安装分别显示具体阻断原因及处理方式。
  - 验证：覆盖中继 error 与连接器 code 两种响应、暂停、离线、权限、超时、任务忙和手机回执；未知状态继续禁止安装。

### 限制

- 检查和安装更新仍须取得有效任务状态；任务运行、权限未核验或发送结果未知时会显示具体原因。
- 手机本地未确认发送记录不自动清除；连接器已接受回执不能替代手机侧核对。

## 0.1.0-alpha.9（2026-10-15）

终端玻璃皮肤、离线字体和彩色随机网格；任务随滚动吸顶，输入框显示实际工作状态。

### 更新

- **皮肤与离线字体**
  - 体验：我的 → 对话与玻璃：三种玻璃、十一种字体、字色和文字阴影；选择保存在本机。
  - 验证：重启读取设置并检查打包字体许可证；代码继续等宽。
- **随机网格动效**
  - 体验：选择光蛇、方块、律动或随机亮格等背景，调整配色、彩色光格、速度与亮度；运行加速，空闲减速或静止。
  - 验证：验证坐标范围、随机路径、速度边界、生命周期与减少动画；不将动画作为执行成功证据。
- **紧凑对话与原任务跳转**
  - 体验：上一轮任务完全离开视窗后显示直角吸顶条，点击返回原消息；Working 与时间位于输入框左上角，同位方形按钮停止。
  - 验证：测试两轮以上滚动边界、原消息定位、历史阅读与真实停止回执。
- **统一选项与模式入口**
  - 体验：问答选项和说明合并为紧凑半透明卡；模式与模型共用弹窗，输入框用竖线分隔。
  - 验证：保留题目版本、加密草稿和未知回执禁重交；未接通模式/模型显示原因。

### 限制

- 模型读取及修改接口尚未提供；不提供模拟模型切换。模式按连接器能力禁用。
- 异步问答仍需在电脑回答；普通问答沿用 alpha.8 链路。
- Android 8–11 使用半透明遮罩，Android 12 以上支持真实背景模糊。
- 构建、签名发布、手机安装与实际验收分别记录。

## 0.1.0-alpha.8（2026-10-14）

普通问答按原题提交并核对Desktop答题记录；异步问题完整显示，当前版本仍须在电脑回答。

### 更新

- **原题问答卡与结果核对**
  - 体验：手机进入等待普通问答的原任务，查看选项说明、选择或填写其他答案；提交后显示已记录或结果待核对，正文仍可阅读。
  - 验证：合成HTTP与原生状态测试覆盖多题、自由输入、旧题、重复提交、电脑先答、丢失回执与持久恢复；真实手机验收另记。
- **特殊交互如实说明**
  - 体验：异步选择题显示完整问题、选项及需要电脑回答的原因；未接通审批、模式和实施入口禁用，不再点击后才返回不支持。
  - 验证：核对固定Desktop的同步回答协议与异步接口限制；确认不开放steer/start回退、不改变权限。
- **加密答题草稿与未知状态**
  - 体验：按账号、执行电脑、任务与题目版本保存答案；重开App仍保留，提交结果未知时不能重交，只能刷新核对。
  - 验证：Android合成存储、HTTP和UI回归验证隔离、秘密输入、保存失败以及未知状态不被pending轮询解锁。

### 限制

- 需配套Windows alpha.15与Android alpha.8；本次普通问答只适配已固定指纹的Desktop 26.1007.2314.0。
- 异步follower接口缺少提问回合绑定，尚不能安全从手机提交；明确提示在电脑处理，不宣称异步闭环已完成。
- 签名发行、现用服务切换和手机真实验收分别记录；此候选不代表已经安装。

## 0.1.0-alpha.7（2026-10-14）

点击原对话时请求电脑自动加载；后台刷新不打扰电脑，慢加载先等待再显示结果。

### 更新

- **点开对话与后台刷新分开**
  - 体验：在任务或动态列表点开对话、点击重试时，只向这台电脑的这一条对话发送一次打开意图；轮询、通知、历史分页和发送后刷新不携带。
  - 验证：验证目标切换隔离、一次性消费、取消后不重放及HTTP参数，配合Windows alpha.14检查未打开对话历史。
- **慢加载保留等待状态**
  - 体验：Desktop尚在加载时短暂等待记录，不重复打开电脑页面或自动发送消息；超时后明确提示重试。
  - 验证：使用合成响应覆盖等待成功、超时、其他错误即时显示，以及切换任务/电脑取消等待。

### 限制

- 自动加载需Windows alpha.14；旧连接器会忽略新参数，仍按原方式读取。
- 此版本不自动新建任务、确认审批或修改权限。
- 签名构建、覆盖安装、手机实测各自记录；源码版本不代表手机已经更新。

## 0.1.0-alpha.6（2026-10-08）

未选择电脑时，手机停止读取任务和动态，并沿用原界面引导选择电脑。

### 更新

- **未选择电脑时先显示选择引导**
  - 体验：打开“远程终端”“任务”或“动态”时，若尚未选择电脑，页面提示先选择电脑；选定后仍可在原界面查看该电脑的任务与动态。
  - 验证：在无选定电脑状态核对任务与动态请求不再发出；选定电脑后检查原任务仍可读取，真实的登录失效与任务不存在错误仍明确显示。

### 限制

- 本版不新增手机端任务创建、审批或模式控制；这些操作仍在 Desktop 完成。
- 在线更新仍要求同一测试渠道和签名证书、已选且已连接的电脑，以及安装前新鲜的空闲、权限与回执证据；下载完成不代表安装成功。

## 0.1.0-alpha.5（2026-10-08）

准备隔离测试环境的受控 OTA 首装基线，沿用现有版本与更新说明入口。

### 更新

- **固定测试渠道发布信任与连续 APK 签名**
  - 体验：计划的受控首装 APK 在“我的 → 版本与更新说明”沿用原有检查入口，使用预置的测试渠道公钥和更新源；安装仍由系统确认。
  - 验证：核对 APK 的包名、versionCode 5、专用签名证书及包内 trust 与审核文件一致，再从同一证书构建下一版验证覆盖更新。

### 限制

- 普通推送和 PR 的 CI debug APK 仍为空 trust、临时签名，不能作为受控首装或连续升级基线。
- 测试 HTTPS origin 已确定但尚未部署；本版受控 APK、手机首装和真实 OTA／同任务验收均未完成。

  - 验证：匿名、过期、跨服务器或端口请求被拒绝；登录账号变化后旧候选不能继续下载或安装。

### 限制

- 需要同源私有中继、固定发布公钥和连续 APK 签名；普通 CI debug 包仍为空 trust。
- 尚未部署私有更新源，也未完成本版手机覆盖安装和同任务验收。

## 0.1.0-alpha.3（2026-10-07）

新增签名 OTA 检查、下载和系统安装入口。

### 更新

- **从“版本与更新说明”检查更新**
  - 体验：查看服务器版本、兼容性、更新说明与下载进度；校验通过后由 Android 确认安装。
  - 验证：错误签名、错误包名、证书不一致或版本重放均拒绝；未配置发布公钥时明确显示不可用。
- **活跃或不确定任务延期安装**
  - 体验：安装前重新读取选定电脑任务状态，并保留本机草稿与账号数据。
  - 验证：运行任务、待审批、发送中或旧连接器缺少实时证据时不进入安装。

### 限制

- 需要受控签名的首次安装包和独立 HTTPS 更新源；普通 CI debug 包没有发布信任。
- 尚未部署公网更新源，也未完成真实手机覆盖安装验收。
