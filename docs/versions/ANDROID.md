# Android 手机端版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.2（2026-10-07）

在手机里查看当前版本和历次更新说明。

### 更新

- **新增“版本与更新说明”入口**
  - 体验：打开“我的”，查看当前版本；点击“版本与更新说明”，阅读本版和旧版记录。每项都写明体验位置和验证方法。
  - 验证：确认顶部版本为 0.1.0-alpha.2，能看到 alpha.2 和 alpha.1 两组记录；上下滚动后返回，原页面与草稿保持原状。
- **更新说明随安装包提供，离线也能读**
  - 体验：进入“我的”后断开网络，再打开更新说明；这里显示的是已安装 App 的记录。
  - 验证：断网后仍能阅读历史，不出现下载进度，也不会自动安装或把服务器版本当成手机版本。

### 限制

- 开发预览，尚未进行本版手机安装和真机联调验收。
- 测试包手动安装；CI debug 签名不保证跨构建覆盖安装。

## 0.1.0-alpha.1（2026-10-07）

独立手机原型，沿用已有聊天与导航界面。

### 更新

- **保留原聊天、草稿、导航和外观设置**
  - 体验：使用“远程终端 / 任务 / 动态 / 我的”；对话继续采用通栏布局和原玻璃控件。
  - 验证：使用专用测试任务检查界面和草稿，确认手机与 Desktop 显示同一任务的后续内容。
- **独立测试包与手动服务器设置**
  - 体验：Desktop Remote Lite 可与旧 App 并存；首次进入自行填写服务器地址，新包不使用旧 OTA。
  - 验证：确认旧 App 仍保留，测试包名为 dev.codex.desktopremote.lite，未自动填入现用服务器或账号。

### 限制

- 此版本已编译并通过 70 项 JVM 单测；没有新包真机验收记录。
- 界面保留的审批、新建任务、模式入口不代表简化版后端已接通。
