# 服务器中继版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.5（2026-10-08）

准备独立受管中继的受控 OTA 首装基线。

### 更新

- **验证签名后在全新 home 建立中继**
  - 体验：受控首装时，维护者使用审核后的测试渠道公钥、已签元数据和源码 ZIP 引导独立中继，再配置新账号、私有路由与 FRPS。
  - 验证：核对 ZIP 完整清单、签名和新受管目录，确认独立监听与委派 cgroup；随后分别验证鉴权下载和专用任务转发。

### 限制

- 仍需外部 Python、独立 HTTPS/FRPS 配置和显式委派的 cgroup v2；不接管现用中继。
- 测试 HTTPS origin 已确定但尚未部署；本版签名首装及真实三端 OTA、同任务验收均未完成。

## 0.1.0-alpha.4（2026-10-08）

中继增加三端私有更新下载与管理员登录更新。

### 更新

- **按账号和设备身份保护更新文件**
  - 体验：私有 HTTPS 更新路径提供三端元数据和包；账号下载三端，活跃设备只下载 Windows。
  - 验证：匿名、过期、撤销、暂停、越组件请求拒绝；插件端口不提供下载；下载期间不能进入服务切换。
- **管理员交互登录后更新服务**
  - 体验：受管安装执行 login 后 check/stage/apply，logout 撤销会话；不用在命令参数里传密码或令牌。
  - 验证：密码不落盘；仅限时会话保存在私有文件；源不匹配、凭据变化或权限错误时停止。

### 限制

- 必须在新的受管中继基线上配置同源 TLS 转发及私有文件目录，不能公开为静态下载。
- 尚未部署现用服务器或验收真实三端在线升级；本批含宿主代码，切换后需要受控宿主重启。

## 0.1.0-alpha.3（2026-10-07）

新增 Linux 受管中继的签名 OTA 命令和独立宿主。

### 更新

- **管理员检查并安装中继更新**
  - 体验：通过本机私有 socket 执行 check、stage、apply、status；现用原中继不会被自动接管。
  - 验证：需要独立受管目录和委派 cgroup v2，任务或审批不明确时延期。
- **保留授权数据和上一版本**
  - 体验：关闭新请求入口，确认空闲后切换版本；验证端口、设备重注册及任务探针后恢复服务。
  - 验证：新版本失败先证明整棵进程树已退出；数据变化或恢复失败时停在可诊断状态，不恢复旧数据库覆盖新数据。

### 限制

- 需要 Linux cgroup v2、首次受管安装和独立 HTTPS 发布源。
- 尚未迁移现用中继或部署公网 OTA；旧中继人工安装保持有效。

## 0.1.0-alpha.2（2026-10-07）

可查询中继本身的运行版本与历史更新说明。

### 更新

- **无需启动服务即可阅读版本与更新记录**
  - 体验：运行 python relay/control_server.py --version 或 --release-notes，分别查看版本和完整中文历史。
  - 验证：不提供 --db 也能查看；命令退出后没有新数据库，也没有新监听端口。
- **已登录账号可查询实际运行的中继版本**
  - 体验：新中继提供 GET /control-api/version；它返回该中继进程启动时载入的版本和更新历史。
  - 验证：合成测试中合法账号得到 relay 版本与历史；未登录和错误令牌被拒绝，FRP plugin 端口不提供此接口。

### 限制

- 尚未部署公网；现用服务器不会因为仓库更新而自动变成此版本。
- 查询版本不证明转发或 Desktop 任务已通过验收。

## 0.1.0-alpha.1（2026-10-07）

提取最小的认证、配对、设备路由与受控转发服务。

### 更新

- **复用账号认证、设备绑定和撤销保护**
  - 体验：在临时数据库和回环服务里完成配对、确认、暂停、恢复及移除设备。
  - 验证：运行 python -B -m unittest discover -s relay -p 'test_*.py' -v，核对未授权请求和已撤销设备均被拒绝。
- **只向登记的目标电脑转发**
  - 体验：手机请求按获授权的电脑标识路由；服务器不会执行 Codex 任务。
  - 验证：通过合成转发测试核对目标隔离和断线行为；不能把本地测试通过当作公网部署完成。

### 限制

- 此版本的 45 项合成测试通过；未部署新 HTTPS/FRP 公网服务。
