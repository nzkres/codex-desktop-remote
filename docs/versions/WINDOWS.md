# Windows 连接器版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.21（2026-10-16）

修复安装激活时的身份锁冲突，提交后自动连接，断开等待既有读取完成。

### 更新

- **修复新窗口启动锁冲突**
  - 体验：原受管连接器安全更新后打开的新窗口。
  - 验证：在GUI后台状态线程启动前读取自动连接策略，避免争用同一非阻塞身份锁；真实Tk合成测试重现alpha.20失败并确认修复后线程退出。
- **自动连接等待更新提交**
  - 体验：下载并安装后，新窗口自动恢复已配对连接。
  - 验证：助手确认激活并写入committed后才自动连接；needs_review、未知或关闭窗口不启动连接，不以看到窗口当升级成功。
- **断开等待手机在途读取**
  - 体验：手机轮询期间在电脑正常断开。
  - 验证：先拦截新读取，在5秒内等待已接收读取保存活动后才确认；超时、未知回执和未确认停止仍保留保护，不停止Desktop任务。

### 限制

- alpha.20已知激活问题由本版替代，旧包不覆盖；原身份、发送回执及保护检查继续保留。
- 仅更新Windows连接器，手机APK与中继不变；实际安装和通道验证单独记录。

## 0.1.0-alpha.20（2026-10-16）

已配对连接器打开后自动连接，候选健康检查保留明确失败原因。

### 更新

- **打开窗口及升级激活后自动连接**
  - 体验：任务空闲后经原受管OTA更新，打开Windows连接器。
  - 验证：已有完整配对且没有运行保护时自动发起一次连接；隔离候选未激活、未配对、暂停或撤销仍不自动连接，不新增开机自启。
- **候选健康诊断不再被统一吞掉**
  - 体验：更新失败时查看state/candidate-health.json；新助手的错误诊断。
  - 验证：保留已知任务、传输与保护错误码，未知异常统一脱敏；健康、空闲、权限、身份及回执校验均保留，失败不重放操作。

### 限制

- 替代alpha.19的新签名包，原alpha.19文件保持不可变；当前实际连接仍alpha.18，发布不代表安装。
- 需任务空闲并正常安全断开后升级；旧助手可能仍显示通用错误，可通过候选健康诊断复核。
- 本轮手机APK和中继程序不更新；未知回执及残留进程继续阻止升级。

## 0.1.0-alpha.16（2026-10-15）

### 更新

- **核验并恢复原连接**
  - 体验：受管连接窗口 → 核验并恢复；持有独占锁检查旧通道进程、原任务和发送/停止回执，通过后保留身份并恢复。
  - 验证：合成测试覆盖旧进程仍在、清单不完整、未知回执、并发身份变化及写盘中断；失败保持保护。
- **新版 Desktop 精确识别**
  - 体验：检测已安装 Desktop 26.1007.9446.0，核验两项固定指纹；恢复时仅更新经过验证的安装路径。
  - 验证：拒绝混合指纹、未知版本和任务权限变化；不改 Desktop 内部文件或权限。

### 限制

- 恢复依赖已验证的旧 Job 崩溃收容与完整当前进程核验，不冒充重建历史 Job 句柄。
- 手机安装更新仍须任务空闲；正常任务继续在 Desktop 执行。
- 本批签名安装、连接恢复和手机更新检查分别记录。

## 0.1.0-alpha.15（2026-10-14）

普通问答按原题提交并核对Desktop答题记录；异步问题完整显示，当前版本仍须在电脑回答。

### 更新

- **原题问答卡与结果核对**
  - 体验：手机进入等待普通问答的原任务，查看选项说明、选择或填写其他答案；提交后显示已记录或结果待核对，正文仍可阅读。
  - 验证：合成HTTP与原生状态测试覆盖多题、自由输入、旧题、重复提交、电脑先答、丢失回执与持久恢复；真实手机验收另记。
- **特殊交互如实说明**
  - 体验：异步选择题显示完整问题、选项及需要电脑回答的原因；未接通审批、模式和实施入口禁用，不再点击后才返回不支持。
  - 验证：核对固定Desktop的同步回答协议与异步接口限制；确认不开放steer/start回退、不改变权限。

### 限制

- 需配套Windows alpha.15与Android alpha.8；本次普通问答只适配已固定指纹的Desktop 26.1007.2314.0。
- 异步follower接口缺少提问回合绑定，尚不能安全从手机提交；明确提示在电脑处理，不宣称异步闭环已完成。
- 签名发行、现用服务切换和手机真实验收分别记录；此候选不代表已经安装。

## 0.1.0-alpha.14（2026-10-14）

配合新版手机，点开未加载的原对话时由 Desktop 自动打开并读取，不再逐条到电脑操作。

### 更新

- **手机按需打开原对话**
  - 体验：Android alpha.7 点开标题或手动重试时，连接器只在原任务没有处理端时请求 Desktop 打开同一对话；后台刷新不会切换电脑页面。
  - 验证：未加载专用原任务经原生入口取得同一ID的快照与历史；合成测试覆盖断开/更新栅栏、并发去重、未知回执、目录变化和异常拒绝。
- **打开过程有明确错误说明**
  - 体验：慢加载、入口不兼容或请求无效时可在错误清单查询原因和源码位置。
  - 验证：核对新错误代码的说明、处理方法和真实源文件位置，源码包必须包含原生打开模块。

### 限制

- 须配合Android alpha.7的显式打开标记；旧手机仍可读取已经加载的对话。
- 原生打开可能让电脑切到目标对话；仅已核对26.1007入口支持自动打开，其他版本保持兼容保护。
- 不创建任务、不自动发送消息、不改变Desktop权限；实际安装与手机验收另记。

## 0.1.0-alpha.13（2026-10-14）

连接器内可查错误代码、具体原因、处理步骤和源码位置；网络失败不再只显示自动重试。

### 更新

- **窗口中的错误清单与代码手册**
  - 体验：主窗口查看当前或最近错误；点击错误清单，按代码或中文搜索，选择一行查看原因、处理步骤和当前版本源码行号，可复制安全说明。
  - 验证：使用合成错误检查详情选择、重复报告去重、恢复后保留历史；未知异常和服务响应不进入界面。
- **明确区分证书、网络与HTTP错误**
  - 体验：证书过期时显示专用代码及服务器续期/重载提示；身份保留，原连接循环继续重试。
  - 验证：覆盖过期证书、不可信证书、超时、DNS、拒绝连接与HTTP状态；恢复后原身份继续使用，错误码清除。

### 限制

- 错误记录仅保留本次窗口最近100项；代码手册不代表实际发生过，持久快照不等于实时诊断。
- 本版不改变任务授权、发送、重试与安全退出规则；不升级Android或中继程序。
- 源码、测试、打包、安装和手机验收分别记录，版本说明不表示本机已升级。

## 0.1.0-alpha.12（2026-10-13）

全部本机对话自动显示标题，点开才读取原生历史；接续沿用每条 Desktop 对话当前权限。

### 更新

- **新对话自动进入手机标题列表**
  - 体验：电脑新建并使用对话后，手机刷新该电脑任务列表即可看到标题，无需添加任务或重新配对。

- **明确区分没有记录和暂时获取失败**
  - 体验：进入对话后展示已有记录；确实为空显示暂无历史，Desktop未就绪时给出原因，使用现有重试入口获取。
  - 验证：空闲空历史、活动空历史、未确认提交、快照超时、权限缺失分别覆盖，失败不会伪装成空记录。
- **沿用 Desktop 权限并保留手机操作的升级保护**
  - 体验：手机接续原对话时使用该任务实时设置；仅标题展示不建立执行连接，手机接入的活动任务及未知发送/停止仍阻止更新。
  - 验证：持久交接记录跨重启保留；读到明确空闲后才释放，升级探针不改数据。旧安装原任务检查保留；身份、未知回执及进程退出保护不放宽。

### 限制

- 需要可核验的本机Desktop执行端；历史标题可见不等于该任务此刻可接续，未就绪时按提示在Desktop打开原对话。
- 旧配置保留selected模式，已获用户批准的安装由维护事务切换all-local；不自动扩大其他电脑安装范围。
- 本机原生目录包含可识别的Desktop记录及旧版未标记来源的候选；不枚举远端、子代理和内部审查，实时读取仍核对本机owner、ID和目录。
- 包、安装和手机新对话实测分别记录；本版不升级Android或中继。

## 0.1.0-alpha.8（2026-10-11）

增加精确 Desktop 26.1007.2314.0 识别及分项重连诊断，保留异常退出和权限保护。

### 更新

- **核对新版 Desktop 后再判断重连条件**
  - 体验：维护者可使用只读诊断区分安装文件缺失、版本不兼容、原任务不可用和权限变化；原连接窗口、身份与任务不变。
  - 验证：旧26.930.7945.0与新26.1007.2314.0仅接受各自两个固定文件指纹；混用指纹、任意其他版本、权限变化、活跃任务或未知回执均拒绝。诊断成功也不授权清除异常退出保护。
- **一次诊断分别列出权限、任务空闲和发送回执结果**
  - 体验：维护诊断的checks字段分别显示三项结果，权限失败不再遮住任务是否空闲和是否有结果不明的消息；不显示消息正文或令牌。
  - 验证：合成权限不符、活跃任务及未确认发送同时出现时，三项分别拒绝；缺失审批状态或异常回执文件也拒绝。本版不增加通用恢复框架；此次实机维护结果单独记录。

### 限制

- 本版是恢复候选；新增兼容识别不等于旧安装已迁移、真实连接恢复或手机验收通过，结果以STATUS为准。
- 异常退出后的runtimeNeedsReview仍要求独立受控恢复证据；不得删除标志、改权限摘要或仅凭端口空闲重连。
- 当前旧安装无法通过普通OTA前检时，不得绕过；维护安装和公网发布须另外完成审查与确认。
