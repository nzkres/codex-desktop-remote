# Windows 连接器版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.6（2026-10-08）

修正同一审核模式的旧新名称造成的手机同步权限误报。

### 更新

- **兼容审核模式旧新名称**
  - 体验：手机查看同一任务历史、Desktop 在该任务接续后，Windows 连接器将 guardian_subagent 与 auto_review 识别为同一审核模式，不再仅因名称变化报告 permissions_changed；原权限摘要与已有配置不改。
  - 验证：用旧、新两种名称生成的摘要做双向兼容验证；真实 reviewer 模式、目录、网络、审批或 profile 改变时仍须拒绝，并在手机同一任务历史及电脑连接器中核对结果。

### 限制

- 本版尚无受控签名发行包、实际安装或手机显示验收；源码和 CI 构建不能证明 OTA 闭环。alpha.5 旧更新预检也会受此缺陷阻断，需先审查维护切换。
- 仅修复审核模式名称兼容；AppX home、首次 404 和配对重试问题仍待分别处理。

## 0.1.0-alpha.5（2026-10-08）

准备隔离测试环境的受控 OTA 首装基线，保留现有连接窗口。

### 更新

- **签名校验后的全新受管目录首装**
  - 体验：受控首装时，维护者核对测试渠道公钥、已签元数据和源码 ZIP 后，在新的 home 引导连接器；窗口继续提供版本与更新说明入口。
  - 验证：核对签名、ZIP 文件清单、运行版本和新目录数据隔离，再用专用 Desktop 任务检查连接与断开；不复制旧配对身份。

### 限制

- 仍需外部 Python、Node、FRP 和固定兼容的 Desktop；没有一体化 EXE 安装器或新 UI。
- 测试 HTTPS origin 已确定但尚未部署；本版签名首装、新测试身份保持与真实 OTA／同任务验收均未完成。

## 0.1.0-alpha.4（2026-10-08）

Windows 私有 OTA 复用本机配对身份，无需另建更新账号。

### 更新

- **使用原配对身份下载私有更新**
  - 体验：完成手机配对确认后在受管窗口检查更新；未配对、认证失败或权限不足有明确提示。
  - 验证：缺失身份时只拒绝、不创建新身份；跨源不发送凭据；设备暂停或撤销后服务器拒绝下载。

### 限制

- 首次仍为维护者安装源码包及外部运行时，没有一体化 EXE 安装器或托盘。
- 私有更新源尚未部署；本版未切换现用身份或完成真实 Desktop/手机 OTA 验收。

## 0.1.0-alpha.3（2026-10-07）

连接窗口接入签名 OTA 和独立更新助手。

### 更新

- **检查、下载并安装新版**
  - 体验：受管安装窗口底部点击“检查更新”，阅读说明后“下载并安装”；先正常断开连接。
  - 验证：在隔离安装运行两版演练；错误签名/损坏下载/任务忙时保留旧版。
- **新旧版本隔离与失败恢复**
  - 体验：独立助手等待原窗口正常退出，校验身份、权限、发送记录和候选运行探针后重开窗口。
  - 验证：候选不健康且进程树已退出才回退；中断、残留或激活结果不明写 needs_review，不盲目重启或覆盖数据。

### 限制

- 本版为可安装的源码运行包，首次需要 Python 3.12、cryptography、固定 Node/FRP；尚无一体化 EXE 安装器或托盘。
- 仅支持全新受管安装；不自动迁移现用身份。公网源和真实 Desktop/手机升级未验收。

## 0.1.0-alpha.2（2026-10-07）

窗口可查看本机版本、更新内容和体验步骤。

### 更新

- **新增“版本与更新说明”按钮**
  - 体验：打开连接窗口，在底部查看版本并点击“版本与更新说明”；可滚动阅读本版和旧版。合成窗口预览也有此入口。
  - 验证：运行 python windows/demo.py，确认版本为 0.1.0-alpha.2；打开说明后能看到 alpha.2、alpha.1 和各自的体验/验证文字，关闭说明不退出连接窗口。
- **窗口、适配器与登记心跳使用同一个连接器版本**
  - 体验：连接器报告自己的实际运行版本，便于在反馈时区分手机、中继与 Windows 的版本。
  - 验证：隔离测试核对窗口版本、适配器健康响应和心跳上报相同；仅更新源码不会把仍运行的旧进程标成新版。

### 限制

- 本版未接管现用实例、迁移身份或做新的真实配对。
- 仍为 Python 窗口原型，没有安装器、托盘或在线更新。

## 0.1.0-alpha.1（2026-10-07）

保留小型连接窗口，跟随一条明确选定的 Desktop 原生任务。

### 更新

- **填写服务器、配对、连接与正常断开**
  - 体验：窗口区分登记心跳与任务通道；正常断开后可重新连接，退出窗口不会停止 Desktop 模型任务。
  - 验证：先运行合成自测，再在独立测试设备上确认同一任务的手机发送、Desktop 接续与手机显示。
- **无需账号的合成预览与只读配置准备**
  - 体验：用 windows/demo.py 预览窗口，用 scripts/configure.py 准备专用任务配置；前者不联网，后者不发送模型输入。
  - 验证：合成预览不生成身份；准备脚本不覆盖已有配置，未知 Desktop 版本或任务不满足要求时明确失败。

### 限制

- 仅支持已固定验证的 Desktop 安装版本与文件哈希。
- 旧实例不能通过复制 DPAPI 或删除保护标志接管。
