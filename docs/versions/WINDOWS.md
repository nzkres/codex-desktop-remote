# Windows 连接器版本历史

由 releases.json 生成；实际运行与验收状态以根 STATUS.md 为准。

## 0.1.0-alpha.11（2026-10-13）

同一台电脑可显式开放多条已有 Desktop 对话，手机分别查看和接续，不替换原测试任务。

### 更新

- **手机查看并继续明确选择的原生对话**
  - 体验：同一已配对电脑的任务列表显示所有已授权对话；点进各自任务读取回复、发送文字或停止该任务回合。
  - 验证：两任务列表、项目、消息回执和同步游标分别核对；同一消息编号不跨任务复用，未列出任务与不匹配权限拒绝。实机安装及手机验收另记。
- **更新和安全断开覆盖所有开放任务**
  - 体验：任一开放任务仍忙碌或有未确认操作时，升级延期；断开先禁止所有任务的新操作，原身份与历史不变。
  - 验证：合成第二任务忙碌、权限变化、未知回执、更新与发送竞态、断开中发送被拒绝；旧单任务配置继续工作。

### 限制

- 任务须在本机明确配置并各自核对权限，不自动扫描或开放所有 Desktop 对话；最多8条，暂无图形添加入口。
- 本版沿用现有手机UI和中继API；没有执行端的任务列为UNKNOWN，进入后显示真实原因。
- 不能在当前正在执行的任务上做升级，必须等待全部开放任务空闲；发布、安装和实机验收分别记录。

## 0.1.0-alpha.10（2026-10-13）

允许原任务在两份明确批准的权限快照之间切换，修复桌面回复后手机同步被误阻断的已审查场景。

### 更新

- **固定保存两份已批准的原任务权限记录**
  - 体验：重启后从手机进入原任务，再在 Desktop 同一任务回复时，连接器可核对两份已批准设置；不自动收录新权限，不需要重复配对。
  - 验证：合成两个完整权限摘要来回切换时读取、发送和正常OTA检查一致通过；第三种权限、未批准网络/目录变化、格式错误、活跃任务和未知回执仍拒绝。实机安装及双向验收单独记录。

### 限制

- 第二份摘要必须由维护者依据用户明确批准的同一任务设置写入，现用配置不会自动迁移或自动学习权限。
- 本版不修改 Desktop 权限、不放宽兼容或异常退出保护；alpha.9故障现场和新候选验收见STATUS。

## 0.1.0-alpha.9（2026-10-13）

简化原任务重连：断网可安全退出，Desktop 执行窗口重建后重新核对原任务，连接状态给出下一步操作。

### 更新

- **断网后正常关闭仍可再次连接**
  - 体验：网络暂断时窗口自动等待恢复；也可主动断开，完成本机退出核验后点击“再次连接”，使用原配对身份。
  - 验证：合成断网→主动断开→原身份重连；未知操作、异常退出、身份变化及任一进程树清理失败仍阻止安全退出。
- **重新找到原任务的 Desktop 执行窗口**
  - 体验：Desktop 的执行窗口重建或 IPC 连接重建后，下一次读取重新寻找同一任务；无需重新配对，不自动重发消息。
  - 验证：合成 owner 切换、快照编号重置、旧广播到达与断线竞态；每次写操作仍核对原任务、目录、完整权限、任务状态和发送回执。
- **状态明确区分登记、传输和手机验收**
  - 体验：窗口说明正在等待网络、登记在线但通道未核对、传输探针已通过或安全断开；探针通过后提示在手机打开原任务。
  - 验证：合成状态切换、终态、保护标志与连续点击测试；静态状态不冒充实时检查，传输通过不冒充手机任务完成。

### 限制

- 本版不自动恢复进程崩溃留下的未知现场，也不修改 Desktop 权限或放宽固定版本检查。
- Windows 仍使用现有源码包及外部 Python/Node/FRP；实际安装、OTA及手机双向消息结果分别记录在 STATUS。

## 0.1.0-alpha.8（2026-10-11）

增加精确 Desktop 26.1007.2314.0 识别及分项重连诊断，保留异常退出和权限保护。

### 更新

- **核对新版 Desktop 后再判断重连条件**
  - 体验：维护者可使用只读诊断区分安装文件缺失、版本不兼容、原任务不可用和权限变化；原连接窗口、身份与任务不变。
  - 验证：旧26.930.7945.0与新26.1007.2314.0仅接受各自两个固定文件指纹；混用指纹、任意其他版本、权限变化、活跃任务或未知回执均拒绝。诊断成功也不授权清除异常退出保护。
- **一次诊断分别列出权限、任务空闲和发送回执结果**
  - 体验：维护诊断的checks字段分别显示三项结果，权限失败不再遮住任务是否空闲和是否有结果不明的消息；不显示消息正文或令牌。
  - 验证：合成权限不符、活跃任务及未确认发送同时出现时，三项分别拒绝；缺失审批状态或异常回执文件也拒绝。本版不增加通用恢复框架；此次实机维护结果单独记录。

### 限制

- 本版是恢复候选；新增兼容识别不等于旧安装已迁移、真实连接恢复或手机验收通过，结果以STATUS为准。
- 异常退出后的runtimeNeedsReview仍要求独立受控恢复证据；不得删除标志、改权限摘要或仅凭端口空闲重连。
- 当前旧安装无法通过普通OTA前检时，不得绕过；维护安装和公网发布须另外完成审查与确认。

## 0.1.0-alpha.7（2026-10-08）

让连接窗口明确显示配对请求未确认的网络故障及下一步核对项。

### 更新

- **配对失败提示与状态复核**
  - 体验：在 Windows 连接窗口提交配对或重开窗口时，若服务器连接失败，会显示申请尚未确认，并提示核对网络、HTTPS 地址、端口和证书；原申请保留，编辑输入框不改变已提交的申请。固定的输入或服务器响应错误可见，未知错误不回显原始详情。
  - 验证：用合成响应分别检查提交结果与重开状态的相同安全提示、固定输入/响应错误的可见原因、未知错误不泄漏；核对申请和身份未被删除或重复提交。受控签发后从已安装 alpha.6 在窗口正常检查、下载并安装 alpha.7，再核对同任务手机与 Desktop 接续及实际运行版本。

### 限制

- 本版仅改善 GUI 错误展示，不实现取消失败申请、重新配对或清理身份；AppX 逻辑/物理 home 问题仍待处理。
- 本版更新须沿原私有 test 源和既有配对身份，先正常断开，再在连接窗口执行更新；下载完成不等于安装成功，实际在线升级和手机验收结果以 STATUS 记录为准。
- Windows 仍是需外部 Python、Node、FRP 和兼容 Desktop 的源码 ZIP，没有一体化 EXE 安装器或托盘。

## 0.1.0-alpha.6（2026-10-08）

修正审核模式别名造成的手机同步权限误报，并准备限于该故障的维护切换路径。

### 更新

- **兼容审核模式旧新名称**
  - 体验：手机查看同一任务历史、Desktop 在该任务接续后，Windows 连接器将 guardian_subagent 与 auto_review 识别为同一审核模式，不再仅因名称变化报告 permissions_changed；原权限摘要与已有配置不改。
  - 验证：用旧、新两种名称生成的摘要做双向兼容验证；真实 reviewer 模式、目录、网络、审批或 profile 改变时仍须拒绝，并在手机同一任务历史及电脑连接器中核对结果。
- **旧版误报的受限维护审查**
  - 体验：已配对的 alpha.5 旧窗口若被同一误报阻断，由维护者在仓库独立执行 alpha.5→alpha.6 的签名本地包 review/apply；审查与用户正常退出原窗口分开，不在连接窗口新增通用安装入口。
  - 验证：核对审查文件30分钟有效期、完整身份/配置/回执绑定、原GUI句柄及同用户会话、候选事务与数据保全；任何身份或真实权限变化、退出不明或候选不健康都应闭锁并保留需复核证据。

### 限制

- 维护工具只在仓库中供审核操作者使用，不随 alpha.6 连接器包交付，也不是通用新用户功能；旧版 alpha.5 的正常 OTA 预检仍会被此故障阻断。
- 本版尚无受控签名发行包、实际安装或手机显示验收，不能声称 OTA 闭环；候选失败后 alpha.5 的已知旧探针缺陷使自动回退健康不能保证，须保留需复核状态。
- 仅修复审核模式名称兼容；AppX home、首次 404 和配对重试问题仍待分别处理。

## 0.1.0-alpha.5（2026-10-08）

准备隔离测试环境的受控 OTA 首装基线，保留现有连接窗口。

### 更新

- **签名校验后的全新受管目录首装**
  - 体验：受控首装时，维护者核对测试渠道公钥、已签元数据和源码 ZIP 后，在新的 home 引导连接器；窗口继续提供版本与更新说明入口。
  - 验证：核对签名、ZIP 文件清单、运行版本和新目录数据隔离，再用专用 Desktop 任务检查连接与断开；不复制旧配对身份。

### 限制

- 仍需外部 Python、Node、FRP 和固定兼容的 Desktop；没有一体化 EXE 安装器或新 UI。
- 测试 HTTPS origin 已确定但尚未部署；本版签名首装、新测试身份保持与真实 OTA／同任务验收均未完成。

## 0.1.0-alpha.4（2026-10-08）

### 更新

- **使用原配对身份下载私有更新**
  - 体验：完成手机配对确认后在受管窗口检查更新；未配对、认证失败或权限不足有明确提示。
  - 验证：缺失身份时只拒绝、不创建新身份；跨源不发送凭据；设备暂停或撤销后服务器拒绝下载。

### 限制

## 0.1.0-alpha.3（2026-10-07）

连接窗口接入签名 OTA 和独立更新助手。

### 更新

- **检查、下载并安装新版**
  - 体验：受管安装窗口底部点击“检查更新”，阅读说明后“下载并安装”；先正常断开连接。
  - 验证：在隔离安装运行两版演练；错误签名/损坏下载/任务忙时保留旧版。
- **新旧版本隔离与失败恢复**
  - 体验：独立助手等待原窗口正常退出，校验身份、权限、发送记录和候选运行探针后重开窗口。
  - 验证：候选不健康且进程树已退出才回退；中断、残留或激活结果不明写 needs_review，不盲目重启或覆盖数据。

### 限制

- 本版为可安装的源码运行包，首次需要 Python 3.12、cryptography、固定 Node/FRP；尚无一体化 EXE 安装器或托盘。
- 仅支持全新受管安装；不自动迁移现用身份。公网源和真实 Desktop/手机升级未验收。

## 0.1.0-alpha.2（2026-10-07）

窗口可查看本机版本、更新内容和体验步骤。

### 更新

- **新增“版本与更新说明”按钮**
  - 体验：打开连接窗口，在底部查看版本并点击“版本与更新说明”；可滚动阅读本版和旧版。合成窗口预览也有此入口。
  - 验证：运行 python windows/demo.py，确认版本为 0.1.0-alpha.2；打开说明后能看到 alpha.2、alpha.1 和各自的体验/验证文字，关闭说明不退出连接窗口。
- **窗口、适配器与登记心跳使用同一个连接器版本**
  - 体验：连接器报告自己的实际运行版本，便于在反馈时区分手机、中继与 Windows 的版本。
  - 验证：隔离测试核对窗口版本、适配器健康响应和心跳上报相同；仅更新源码不会把仍运行的旧进程标成新版。

### 限制

- 本版未接管现用实例、迁移身份或做新的真实配对。
- 仍为 Python 窗口原型，没有安装器、托盘或在线更新。

## 0.1.0-alpha.1（2026-10-07）

保留小型连接窗口，跟随一条明确选定的 Desktop 原生任务。

### 更新

- **填写服务器、配对、连接与正常断开**
  - 体验：窗口区分登记心跳与任务通道；正常断开后可重新连接，退出窗口不会停止 Desktop 模型任务。
  - 验证：先运行合成自测，再在独立测试设备上确认同一任务的手机发送、Desktop 接续与手机显示。
- **无需账号的合成预览与只读配置准备**
  - 体验：用 windows/demo.py 预览窗口，用 scripts/configure.py 准备专用任务配置；前者不联网，后者不发送模型输入。
  - 验证：合成预览不生成身份；准备脚本不覆盖已有配置，未知 Desktop 版本或任务不满足要求时明确失败。

### 限制

- 仅支持已固定验证的 Desktop 安装版本与文件哈希。
- 旧实例不能通过复制 DPAPI 或删除保护标志接管。
